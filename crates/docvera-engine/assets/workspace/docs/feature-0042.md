# Offline documentation

## Overview

Read, validate and search Markdown without a server.

## Requirements

### REQ-1 Local persistence

Markdown files remain the source of truth.

### REQ-2 Structured search

Retrieve individual sections with SQL and full-text search.

## Security

Use OAuth 2.0 with PKCE when a future remote service is introduced.
