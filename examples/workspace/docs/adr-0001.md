# Local-first storage

## Context

Documentation must remain available offline.

## Decision

Store authoritative Markdown in Git. Use SQLite as a disposable local index.
See [requirements](feature-0042.md#requirements).

### Implementation

```bash
docvera index --rebuild
```

## Consequences

Rebuild the index after cloning. No remote database is required.
